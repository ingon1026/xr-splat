## 3. 실행 통합 — 단일 현관 `xrsplat` (가장 중요)
```bash
python xrsplat.py build <scene|config> [--force]   # 01→08 + 게이트 + report + 결과팩 (resume: 완료단계 skip)
python xrsplat.py showcase <scene>                 # 결과팩만(mp4·gallery·localize→render·궤적·지표)
python xrsplat.py report   <scene>                 # XR-ready 판정
python xrsplat.py view     <scene> [--port 8080]   # 3D 뷰어(브라우저)
python xrsplat.py localize <scene> <query.png> [--render-out out.png]
python xrsplat.py run      <scene> <frames_dir>
```
- **단일 진실원** `pipeline/config.py` + `configs/<scene>.yaml` (input·단계별 knob·경로 해석).
- **오케스트레이터** `pipeline/orchestrator.py`: `build(cfg)` — 함수호출(01,03,04,06,07,08)+subprocess(02 bash,05 gate). 게이트 강제(05 PASS+프레임무결성 전 학습차단), resume(산출물 있으면 skip), 끝에 build_report.
- **런타임 API** `pipeline/merged_map.py`: `MergedMap(scene).localize/render/run` (PnP/photometric 교체).
- **결과팩** `scripts/make_showcase.py`.
- 검증됨: home build=전단계 skip→XR_READY(idempotent), room2 build=실제단계 다 돌림(01-04 skip→05 PASS→06학습→08→report), localize home=28dB·28FPS.

## 5. 함정/주의 (실행·이어받기 필수)
- **env**: `source scripts/env.sh` 필수(JIT gsplat=gcc-11). 긴 작업 setsid 배경+로그 tail. `pkill -f` 자기 명령줄 겹침 금지.
- **resume edge-case**: 오케스트레이터 04-skip은 `points_init.ply` 존재로 판정하나 **train은 `points3D.txt`를 읽음** → points3D 비어있으면(0) 학습 init 실패. 새 scene은 `04_make_pointcloud --scene <s> --n <KF수>`로 points3D 먼저 채워라(향후 04-skip을 points3D 내용으로 강화 권장).
- **"28m walk" 정정**: 학습된 orbframe 자산은 전체 29m 녹화 중 **68~85s 구간(2m bbox)** 만. 풀 28.8m은 `ros2_bag2_home_rgbd`(242 KF) 따로 학습한 것.
- **품질↔범위**: 풀 28.8m은 밀도 퍼져 soft(22dB), 좁은 2m은 28dB. room2(8000iter·narrow)는 6dB(통합 검증용).
- **렌더 품질 신성불가침**(인곤님 절대 제약): 렌더는 항상 풀 자산(`cfg.asset_ply`). localize는 lite/저해상도 자유.
- **mp4·outputs/는 gitignore** → 결과팩·.ply는 git에 안 올라감(재생성 가능). 코드/이미지만 커밋.
- **orchestrator 로그 버퍼링**: build 중 로그파일 비어보일 수 있음(작업은 정상, 산출물로 확인).
- **GPU 1개**: 두 GPU 작업 동시면 transient CUDA 에러(merged_map 테스트가 그때 1-fail). 클린 재실행하면 28 passed.
